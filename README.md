# Yiddish Offline (Expo / React Native) — גרסה 2.0
אפליקציה ללימוד יידיש בלי חיבור לאינטרנט: כרטיסיות, חזרה חכמה, חידונים, זיווג וחיפוש.
כל המילים נמצאות ב-`vocabulary.json`.

    npm install
    npx expo start --android

## מה חדש ב-2.0
- אוצר מילים: 1,224 מילים וביטויים (במקום 754), קטגוריות חדשות: בית כנסת ולימוד, זמן ולוח (כולל חודשים עבריים), פתגמים.
- משפטי דוגמה, הערות הגייה/דיאלקט, וסימון דער/די/דאָס (בחלק מהמילים).
- חידון: בחירה, הקלדת תעתיק (עם סבלנות לטעות אחת), ספרינט 60 שניות, כיוון מעורב, הסבר אחרי כל תשובה.
- כרטיסיות: סיכום סבב, חזרה על הטעויות, "רק חדשות", כרטיס פרטי מילה עם שיתוף ודיווח.
- נקודות ורמות, הישגים, גרף פעילות שבועי, שיא זיווג, ערכת נושא אוטומטית/בהירה/כהה, גודל טקסט נוסף, רטט.
- התקדמות קיימת נשמרת (מזהי המילים נשארו תואמים).

## מבנה רשומה ב-vocabulary.json
`c` קטגוריה · `y` יידיש · `t` תעתיק · `h` עברית · אופציונלי: `g` מין (d/f/n) · `n` הערה · `e`/`et`/`eh` משפט דוגמה (יידיש/תעתיק/עברית) · `o` תרגום ישן (לשמירת התקדמות; לא למחוק)
הקטגוריות מוגדרות ב-`TOPICS` בתחילת `App.js`.

## בניית APK ב-GitHub
דחיפה ל-`main` (או הרצה ידנית מלשונית Actions) מפעילה את `main.yml`. בסיום מורידים את `yiddish-offline-apk` מה-Artifacts.
