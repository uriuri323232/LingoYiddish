# Yiddish Offline (Expo / React Native) — גרסה 2.2
אפליקציה ללימוד יידיש בלי חיבור לאינטרנט: כרטיסיות, חזרה חכמה, חידונים, זיווג וחיפוש.
כל המילים נמצאות ב-`vocabulary.json`.

    npm install
    npx expo start --android

## מה חדש ב-2.2
- **תוקנו כל קבצי האייקון** (`icon.png`, `adaptive-icon.png`, `adaptive-mono.png`, `splash-icon.png`): חלקם הגיעו ריקים או כתמונת placeholder, והבנייה עלולה הייתה להיכשל. נוצרו מחדש לפי `icon.svg`.
- מהיר יותר: מסך הבית מחשב סטטיסטיקות רק כשההתקדמות משתנה, החיפוש מגיב בלי לתקוע את ההקלדה, ורשימת התוצאות נטענת בחלקים.
- קרדיט קטן בתחתית מסך הבית.
- ניקוי הפרויקט: הוסרו workflow כפול (`main.yml` ותיקיית `github/` שלא בשימוש) וארכיון ישן. כעת בנייה אחת, `build-apk.yml`.

## מה חדש ב-2.1
- ממשק משודרג: פלטת צבעים עדינה יותר, כרטיסים עם מסגרת וצל רך, כפתורים וסרגל תחתון צפים, פס התקדמות דק, משוב לחיצה, וברכה לפי שעות היום במסך הבית.
- תוקן קובץ האייקון המונוכרומטי (`adaptive-mono.png`) שהיה פגום בארכיון.

## מה חדש ב-2.0
- אוצר מילים: 1,224 מילים וביטויים (במקום 754), קטגוריות חדשות: בית כנסת ולימוד, זמן ולוח (כולל חודשים עבריים), פתגמים.
- משפטי דוגמה, הערות הגייה/דיאלקט, וסימון דער/די/דאָס (בחלק מהמילים).
- חידון: בחירה, הקלדת תעתיק (עם סבלנות לטעות אחת), ספרינט 60 שניות, כיוון מעורב, הסבר אחרי כל תשובה.
- כרטיסיות: סיכום סבב, חזרה על הטעויות, "רק חדשות", כרטיס פרטי מילה עם שיתוף ודיווח.
- נקודות ורמות, הישגים, גרף פעילות שבועי, שיא זיווג, ערכת נושא אוטומטית/בהירה/כהה, גודל טקסט נוסף, רטט.
- התקדמות קיימת נשמרת (מזהי המילים נשארו תואמים).

## מבנה רשומה ב-vocabulary.json
`c` קטגוריה · `y` יידיש · `t` תעתיק · `h` עברית · אופציונלי: `g` מין (d/f/n) · `n` הערה · `e`/`et`/`eh` משפט דוגמה (יידיש/תעתיק/עברית) · `o` תרגום ישן (לשמירת התקדמות; לא למחוק)
הקטגוריות מוגדרות ב-`TOPICS` בתחילת `App.js`.

## בניית APK ב-GitHub
דחיפה ל-`main` (או הרצה ידנית מלשונית Actions) מפעילה את `build-apk.yml`. בסיום מורידים את `yiddish-offline-apk` מה-Artifacts.
